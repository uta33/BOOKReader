# ADR 0001: Cloudflare Worker認証・完全同期

状態：採用

## 決定

- Cloudflare Workers + D1をAPI・認証・同期の正規基盤とする
- 初回は匿名、任意でWorker側Google OAuthへ連携する
- OAuth完了は256bit ticketのポーリングとし、認証情報をディープリンクへ載せない
- 競合はレコード単位LWW、読書位置だけMAX
- Google identity衝突時は自動統合せず三択を表示する
- PWAはローカル保存のままWorkerへ直接接続し、Vercel Functionsは旧URL互換の
  薄型プロキシとして残す

## 理由

APKの秘密鍵露出と無認証APIの請求リスクを先に解消し、Expo Goを維持しながら
端末喪失時の復元と複数端末同期を追加するため。

## 帰結

- content本の本文は別端末へ同期されず、再取り込みが必要
- アカウント統合は不可逆なので、冊数と削除件数を明示する
- 統合・クラウド切替後は強制スナップショットで正本を入れ替え、古い匿名データの
  再pushを防ぐ
- 一般公開前に署名付きAPKを14日・10冊で本人運用する
