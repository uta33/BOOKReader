# ADR 0003: ドッグイヤーの音声入力

状態：採用

## 決定

- 抜き書きとコメントの両方で、日本語の音声入力を提供する
- 利用者が「音声入力」を押したときだけマイク権限を求め、認識途中の文字も入力欄へ表示する
- 認識結果は既存文字を上書きせず、次の行へ追記する
- Android／iOSが選択している標準の音声認識サービスを使い、独自の有料文字起こしAPIは追加しない
- 録音データは保存・同期せず、利用者が確認して保存した文字だけをDogEarとして扱う
- 音声入力を利用できない端末でも、従来の手入力とキーボード音声入力を残す

## 理由

長い抜き書きを手で入力する負担を下げ、読書中の記録を継続しやすくするため。
端末標準サービスを使えば、アプリ固有のAPIキー、従量課金クォータ、録音保管基盤を
追加せずに実現できる。

## 帰結

- 音声入力にはマイク権限が必要
- 認識が端末内で完結するかネットワークを使うかは、OS、端末、選択中の音声認識サービス、
  ダウンロード済み言語モデルによって異なる
- 音声入力部分はExpo Goに含まれないため、preview APKまたはdevelopment buildで実機確認する
- 誤認識を前提に、確定前の入力欄を表示し、利用者が修正してから保存できる状態を維持する
