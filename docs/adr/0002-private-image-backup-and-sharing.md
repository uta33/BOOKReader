# ADR 0002: 非公開画像バックアップとAndroid共有

日付：2026-08-01

## 決定

- 抜き書き画像の実データをCloudflare R2、所有権と容量をD1へ保存する。
- 端末間で同期するのはランダムな画像IDだけとし、端末ファイルURIは同期しない。
- 画像APIはBearer認証と所有者照合を必須にし、公開URLを作らない。
- Android Sharesheetは単一のテキスト・URL・画像だけを受け取る。
- 共有内容は保存先の本と内容を利用者が確認してからローカル記録へ追加する。
- Obsidian更新は管理マーカー内に限定し、マーカー外の利用者編集を保持する。

## 理由

図やグラフを含む抜き書きを端末紛失から復元しつつ、端末固有URIや公開画像URLを
クラウド正本にしないため。Android共有は入力経路を増やすが、対応MIMEを狭くし、
明示保存を挟むことで意図しない取り込みを防ぐ。

## 上限

- 12MB/画像
- 500画像/アカウント
- 250MB/アカウント
- SVG、音声、動画、複数共有は対象外
